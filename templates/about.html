ABOUT THE PROJECT

Sales Report Automation

A Python-based web application for processing sales data and generating business reports.

Project workflow

  1. Upload Excel / CSV input
  2. Validate required data and detect duplicates
  3. Calculate achievement percentage
  4. Apply incentive-rate thresholds
  5. Generate Excel report, summary and error report
  6. Display dashboard metrics

Assessment business rules

Achievement % = (Achieved ÷ Target) × 100

Achievement ≥ 120%: 15% incentive rate

Achievement ≥ 100%: 10% incentive rate

Below 100%: 0% incentive rate

The assessment's example refers to Salary when calculating incentive amount, but Salary is not included in its specified input columns. This version therefore shows the incentive rate only. Confirm the incentive base with your project guide before calculating a payout amount.
